# bd-stubs

A type stub repository for Ballsdex. It is recomended to install bd-stubs with all dependencies for improved typing.
Without it, important types for packages such as discord.py won't appear.

```bash
uv add "bd-stubs[all] @ git+https://github.com/Caylies/bd-stubs@0.1.2"
```

## Modules typed

| ------------------------------ | ------ |
| ballsdex                       | ⏳     |
